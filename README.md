# Jai Mendiratta — Professional Portfolio

Single-page static professional portfolio, ready for GitHub Pages.

## Publish on GitHub Pages
1. Log into Jai's own GitHub account.
2. Create a **public** repository named `USERNAME.github.io` (replace USERNAME with exact GitHub username).
3. Upload `index.html` and `jai-portrait.jpg` to repository root.
4. Under repository Settings → Pages, choose Deploy from branch `main` and folder `/(root)`.
5. Visit `https://USERNAME.github.io` when deployment finishes.

## Before publishing
- Review and approve every position, timeline, accomplishment, email, phone number and photo.
- The two supplied career documents differed on the date for Head of Digital Programmes; this site intentionally uses a consolidated BBC period rather than a disputed promotion date.
- The portrait is an AI-edited image. Check resemblance against the original; replace with unretouched image if needed.
- The contact information is public once the site is deployed.
